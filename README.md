# לומדת EMU – Video EEG

גרסת פיתוח של לומדה בעברית לסטודנטים לסיעוד המשגיחים על מטופלי Video-EEG.

## הרצה מקומית
```bash
pip install -r requirements.txt
streamlit run app.py
```

## מה כלול
- 11 פרקי לימוד בעברית ו-RTL
- placeholders לסרטון פתיחה, סרטוני התקפים ותמונות EEG
- פרק Persyst Online
- פרוטוקול פעולה בזמן אירוע ובזמן פרכוס
- מבחן 20 שאלות, ציון מעבר 75%
- שמירת תוצאות ב-SQLite
- מסך ניהול וייצוא CSV

## לפני שימוש קליני/פריסה ציבורית
1. לאשר את התוכן והנוהל מול הנהלת היחידה והסיעוד.
2. להוסיף אימות משתמשים ומנהל.
3. לבחור אחסון מאובטח ומאושר לסרטוני מטופלים; אין להעלות חומר מזוהה לשרת ציבורי ללא אישורים מתאימים.
4. להחליף SQLite במסד נתונים מתמשך אם הפריסה אינה מבטיחה דיסק קבוע.
5. להוסיף מדיניות פרטיות, הרשאות וגיבוי תוצאות בהתאם למדיניות הארגונית.

## חומרי מדיה ששולבו בגרסה זו
כל המדיה נמצאת בתיקיית `media/` ומוצגת אוטומטית בפרק המתאים:
- `intro.mp4` – סרטון פתיחה של ד״ר הרשקוביץ
- `fia.mp4` – התקף מוקדי עם פגיעה במודעות
- `tc.mp4` – התקף טוני־קלוני
- `pnes.mp4` – אירוע תפקודי
- `normal_eeg.png` – תרשים EEG תקין
- `eeg_seizure.png` – תרשים EEG בזמן התקף

הווידאו עבר המרה לגרסה מוקטנת לצורכי הצגה בלומדה; המקור אינו נכלל בחבילה. יש לוודא הסכמות והרשאות לפני הפצה, ובפרט אין לפרוס את הסרטונים בענן ציבורי ללא אישור אבטחת מידע ופרטיות.

## עברית וכיוון כתיבה
ממשק הלומדה מוגדר RTL. שמות קובצי המדיה באנגלית לצמצום בעיות נתיבים, אך הכותרות והתוכן בעברית.


## כניסה עם קוד משותף (גרסה חדשה)

הגישה לתוכן הלומדה מחייבת קוד משותף, ומסך הניהול מוגן בסיסמה נפרדת.

להרצה מקומית: העתיקו `.streamlit/secrets.toml.example` אל `.streamlit/secrets.toml`, והחליפו את שני ערכי הדוגמה בסיסמאות חזקות. אין להעלות את `secrets.toml` ל־GitHub.

ב־Streamlit Cloud: פתחו App settings → Secrets והכניסו שם את שני המשתנים `EMU_ACCESS_CODE` ו־`EMU_ADMIN_PASSWORD` בפורמט TOML.

**חשוב:** הקוד המשותף אינו תחליף לאימות זהות אישי, ו־SQLite מקומי אינו אחסון תוצאות מתמשך ומהימן ב־Streamlit Community Cloud. לפני פריסה עם סרטוני מטופלים או פרטי סטודנטים יש לקבל אישור אבטחת מידע ולבחור אחסון מאובטח.
